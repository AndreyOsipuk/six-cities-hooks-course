# Вёрстка «Шести городов»

Статическая HTML/CSS-вёрстка всех страниц и состояний приложения. По ней вы собираете React-приложение: разметку переносите в компоненты, стили подключаете как есть.

Открыть в браузере: `markup/index.html` (оглавление) или любую страницу напрямую. Для корректной работы путей лучше через локальный сервер:

```bash
npx serve markup
```

## Макет в Figma

https://www.figma.com/design/87T3S99hWo2FTCXa3e4f2l

- **Компоненты** - переменные цветов (`color/*`), текстовые стили, тени и компоненты: логотип, кнопка, «Избранное», метка Premium, рейтинг, маркер карты, вкладка города, карточка предложения, шапка.
- **Экраны - десктоп** - главная, страница предложения, вход.
- **Экраны - телефон** - главная.

Остальные страницы и состояния - в HTML-вёрстке ниже, она главный источник. Шрифт в макете - Inter (в вёрстке - системный шрифт).

## Страницы

| Файл | Что это |
|------|---------|
| `main.html` | Главная: города, список предложений, карта, поиск, сортировка (меню открыто), «Recently viewed». На телефоне - переключатель «List / Map» |
| `main-empty.html` | Главная без предложений: «No places to stay available» |
| `offer.html` | Страница предложения, пользователь вошёл: галерея, детали, хозяин, отзывы, форма отзыва, карта и соседние предложения |
| `offer-not-logged.html` | Та же страница для гостя: без формы отзыва |
| `login.html` | Вход: форма, пример ошибки валидации, кнопка случайного города |
| `favorites.html` | Избранное, сгруппированное по городам |
| `favorites-empty.html` | Пустое избранное: «Nothing yet saved» |
| `404.html` | Страница «404 Not Found» |
| `states.html` | Витрина вспомогательных состояний: спиннер, ошибка сервера, «нет сети», уведомление об ошибке, кнопка и форма в процессе отправки |

## Скриншоты

`screenshots/<страница>-desktop.jpg` (1440 px) и `screenshots/<страница>-mobile.jpg` (375 px) - каждая страница во всю высоту. Пересоздать после правок вёрстки (нужен Google Chrome):

```bash
node markup/tools/screenshots.mjs http://localhost:4173 markup/screenshots
```

## Стили

- `css/main.css` - общие стили: цвета и размеры (CSS-переменные в `:root`), шапка, кнопки, карточка предложения, рейтинг, кнопка «Избранное», карта, поля форм, подвал, пустые состояния.
- `css/main.css` также содержит общие вспомогательные элементы: спиннер, плашку «нет соединения», уведомления (тосты).
- `css/pages/*.css` - стили конкретных страниц. Форма отзыва описана в `css/pages/offer.css`.

Брейкпоинты: телефон до 767 px, планшет 768-1143 px, десктоп от 1144 px. Вёрстка проверена на ширинах 320, 375, 768, 1024 и 1440 px.

## Состояния элементов

Состояния задаются классами-модификаторами - в приложении вы переключаете их из React:

| Элемент | Класс | Когда |
|---------|-------|-------|
| Город | `cities__link--active` | выбранный город |
| Меню сортировки | `sort--opened` | меню открыто |
| Пункт сортировки | `sort__option--active` | выбранный вариант |
| Пункт сортировки | `sort__option--focused` | выделен стрелками с клавиатуры |
| Карточка | `place-card--active` | курсор над карточкой (подсветка маркера) |
| Кнопка «Избранное» | `bookmark--active` | предложение в избранном |
| Маркер на карте | `map__pin--active` | активное предложение - оранжевый |
| Поле формы | `field--error` | ошибка валидации |
| Рейтинг | `style="--rating: 80%"` | 20% на звезду, округление до целого - в коде |

## Карта

В вёрстке карта - нарисованная схема с маркерами (`img/map.svg`), чтобы было видно, где она стоит и как выглядят маркеры. В приложении на её месте - **Яндекс Карты** (хук `useYandexMap`), маркеры - синие и оранжевый, как в вёрстке.

## Картинки

- `img/offers/` - фотографии жилья, лицензия CC0 (источники - `img/SOURCES.md`). Те же фото отдаёт учебный сервер.
- `img/avatars/` - нарисованные аватары хозяев и авторов отзывов.
- Остальные иконки и иллюстрации нарисованы для проекта.
